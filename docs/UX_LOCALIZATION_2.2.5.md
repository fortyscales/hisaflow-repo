# HisaFlow Desktop v2.2.5 — Pinned Chrome & Kiswahili pass

- Screen chrome now paints all the way to the top edge of each scrolling pane so content cannot show through above sticky controls.
- Activity Log, Staff, Suppliers, Products, Customers, Credit and Orders pin their search controls with the screen header. Search remains available even when a collection or result set is empty.
- Finance UI added in v2.1–v2.2 is now connected to the existing English/Kiswahili language system, including Accounts, Reports and account-selection labels used by expenses, credit payments and sales status.
- User-entered names (products, accounts, customers, suppliers) are intentionally never translated.
